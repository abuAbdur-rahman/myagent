# Release v0.10.2 - Calmer working state, grouped tools and inline errors

Status: release candidate on 2026-11-07. Follows v0.10.1. Migration 32 adds a
nullable `messages.error` column.

## What changes

- The step counter only appears after the first tool round. A turn that answers
  without calling a tool shows Thinking and elapsed time, not `step 1/25`.
- Repeated tool calls fold into one expandable row per tool: `Searched the web ·
  4`, `Read pages · 6`, `Checked the time · 2`. A single call still shows on its
  own. The collapsed row opens to the individual calls and their previews.
- A failed turn shows an inline error card in the reply, with a plain-language
  heading and hint for internet connection, API key, model, rate limit, context
  length, blocked request or provider server. Technical details are collapsible.
  Retry is offered when the turn can be retried.
- The memory review bar has Accept all when more than one note is pending. It
  saves every pending note for the current chat or project and reports the count.
- Only the working chat shows the activity pill. Other chats can be opened while
  a turn runs; the working chat is marked with a spinner in the sidebar, and its
  live output is restored when you return. Sending in another chat waits for the
  active turn instead of starting a second stream.

## Verification

- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`,
  `npx tsc --noEmit`, `npm test`, `npm run build`, `fallow dead-code`.
- New tests cover grouped tool rows, the step event starting after the first
  tool, friendly stream-error classes, and the inline error on a failed turn.
  Migration 32 is covered by the migration suite.

## Not in this release

- Concurrent sends in two chats. One turn runs at a time; the other chat can be
  opened and drafted in, and sending waits for the active turn.
- Background approvals: an approval raised by a background chat still uses the
  single approval surface.
- Tool groups are grouped by tool name, not by time range, so the children keep
  their original order inside the group.
