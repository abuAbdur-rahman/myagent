# Release v0.9.1 - Hold-to-talk capture and prompt budget

Status: release candidate on 2026-11-06. Follows v0.9.0. No migration.

## What changes

- Hold-to-talk no longer loses the start of an utterance. The audio context and
  the PCM worklet are prepared once at mount instead of on every press, the
  worklet flushes its partial buffer before teardown, and the recorder refuses a
  context that never reached `running`. A press that is released before the
  microphone is ready now says "Recording too short" instead of doing nothing.
- The capture gate measures the loudest 50 ms window instead of the whole hold,
  so leading and trailing silence cannot dilute a short word. Silence is trimmed
  with 100 ms of padding before transcription, the minimum clip is 0.3 s, and a
  blank local transcript is an error instead of an empty success.
- The four outcomes are now distinct: no audio captured, recording too short,
  the microphone recorded silence, and no speech detected. Backend strings map
  to those messages, so `internal:` prefixes no longer reach the user, and the
  activity pill shows "Starting microphone" while the device opens.
- The prompt budget keeps instructions whole. Instructions are reserved first,
  data blocks fit into the remainder in order, and an over-budget turn ends with
  a line saying how many blocks were left out. A truncation can no longer cut a
  memory note or a project instruction in half.
- Untrusted memory notes never enter the prompt as trusted prose. The renderer
  filters them and the client now carries the file's trust flag, which was being
  dropped when notes were read.

## Verification

- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`,
  `npx tsc --noEmit`, `npm test`, `npm run build`, `fallow dead-code`.
- New frontend tests cover the loudest-window level, silence trimming, the four
  capture outcomes, the instruction reserve, the over-budget trailer and the
  untrusted-note filter. New Rust tests cover the clip checks and blank
  transcripts.

## Not in this release

- The project Context pool (document write and read tools, memory-to-context
  override links, document export) is a feature and stays for 0.10.0.
- Consolidation and the jev verifier remain unshipped.
