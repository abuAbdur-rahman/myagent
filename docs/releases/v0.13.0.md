# Release v0.13.0 - project and provider refresh, attachments in project chats

Status: release candidate on 2026-11-12. Follows v0.12.0. No migrations.

## What changes

- Projects are listed as a card grid with review and activity chips, and a
  project page splits into the conversation and a context rail. A project chat
  can start without leaving the page: files, images and a dictated note are
  attached in the composer and carried by the first turn.
- Attached documents are deduplicated per project, their extracted text follows
  the project, and images that arrive without a MIME type are resolved from
  their extension instead of being refused.
- Providers are listed as cards with OpenRouter, DeepSeek and Ollama brand marks
  and the add-provider dialog is a tile picker. Arrow keys move focus with the
  selected provider, so Space and Enter no longer reopen the previous one.
- Inline visuals reveal the frame body again, and the injected frame report adds
  the app mode, accent and design tokens so a visual matches the theme it opens
  in. That theme block is bounded and counted in the context budget.
- Memory extraction asks the model for scored facts and keeps only what clears
  the salience threshold. Vision trusts the model families the app knows and
  honours the manual override instead of a catalog that reports no image
  support.
- Project-chat startup is bounded to the selection that started it: a pending
  start cannot replace a later project or conversation, late attachment results
  are discarded after a switch, and a failed start rolls back only while it
  still owns the selection.

## Verification

- `npx tsc --noEmit`, `npm test`, `cargo fmt --check` and `cargo test` pass
  locally, with 687 web tests and 489 Rust tests (11 ignored).
- The PR review gate is CodeRabbit. Its findings were fixed before merge,
  including the startup-ownership and rollback-scope races it flagged on the
  fixes themselves.

## Not in this release

- Provider capability metadata is not fetched for request-inspector effort
  clamping; displayed request size remains an estimate.
- Folders, permission modes, on-demand tool definitions, code mode, project
  instruction files, cost caps, model compare, cheap-model routing, quick ask,
  branch-tree navigation, scheduled runs and the local navigator remain
  unshipped.
