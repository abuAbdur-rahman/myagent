# Release v1.0.0 — target: integration, eval and security

Status: target, not shipped. Baseline: 0.8.0.
0.8.0 execution plan: `docs/plan/v0.8.0-hardening.md`.

Final release for now. 1.0.0 integrates the MCP and computer-use work, proves it
on a clean Windows machine and closes the security review. It does not start a
new protocol experiment and does not add a new platform. The older “comfortable
daily driver” wishlist below is backlog, not a 1.0.0 commitment; verify every
item in `docs/features.md` before pulling it in.

## Shell around the agent
- C1 provider storage verified, C2 picker polish, G3 settings page,
  G2 shortcuts (Esc stop, new chat, search, settings), A8 queue while
  streaming, G4 theme vars, G5 completion notification, G6 debug log
  (no secrets), E5 prompt overrides, F1 artifact versions, F5
  Mermaid/LaTeX lazy renderers.

## Data + projects
- B6 folders (plain organization), B3/B5 pins + list polish, A13 tags
  from title model, E1/E6 memory roll-up per plan.

## Differentiators shipped one at a time
- J1 context inspector, J2 cost cap, J5 cheap-model routing, J4 local
  models, J3 side-by-side compare, J7 branch tree, J10 artifact export,
  J6 quick-ask hotkey, J11 scheduled runs, G7 auto-update.

## Added after 0.6.1
- 0.7.0 MCP setup UX: standard `mcpServers` import/export, Windows
  spawn/PATH/job-object handling, server logs and tool-hash re-approval.
- 0.8.0 MCP protocol refresh: Rust-owned state machine and `server/discover`
  fallback. Full scope: `docs/plan/v0.8.0-hardening.md`.
- 0.7.0 Windows computer use (J13): observe and act through a bundled UIA
  MCP server, with per-app tiers, hard denies, kill switch and audit.
- 0.8.0 hardening: eval, lazy Chromium, DPI/multi-monitor and orphan cleanup.
- 0.8.0 optional local navigator (J14): jevos-v5 CPU verifier, shadow mode,
  only if the benchmark gates pass.
- 1.0.0 integrates both, runs the clean-machine eval and security review.
  See `docs/plan/v0.8.0-hardening.md`.

## 1.0.0 gate

- Computer use integrated into the MCP settings and approval surfaces.
- Documentation, in-app changelog and installer checks finished.
- MCP and computer-use eval sets re-run on a clean Windows machine.
- Security review covers secrets, MCP transports/OAuth, the permission engine,
  computer-use tiers/hard denies/audit and the installer.
- The optional local navigator ships only if the 0.8.0 gates passed; otherwise
  it is omitted and the result is recorded.
- No open high or critical security finding.

## Not in 1.0.0

- New MCP protocol experiments beyond the 0.8.0 discovery/headers/cache work.
- Roots, Sampling or Logging.
- macOS, Linux or mobile branches.
- An elevated agent, secure-desktop input, a raw shell in the computer-use
  server, remote steering or a local vision model.
- The older v1 wishlist in this file, unless it is explicitly pulled in.
