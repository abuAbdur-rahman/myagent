# Release v0.11.0 - UI overhaul, artifact CDN previews, read-aloud and reply timing

Status: release candidate on 2026-11-08. Follows v0.10.2. Migrations 33 and 34
add nullable `messages.duration_ms` and `messages.completed_at`.

## What changes

- The shell, chat, projects, providers and settings surfaces are rebuilt on warm
  semantic tokens with light and dark themes, serif page titles, a single accent
  per view and visible keyboard focus.
- Artifact previews run normal inline JavaScript and load HTTPS CDN scripts,
  styles, images and fonts, including Tailwind and icon sets. Form controls,
  modals and popups work, and JavaScript handles their interactions. Native
  form submission through an action is still blocked. The untrusted frame stays
  on an opaque origin without `allow-same-origin`; `connect-src 'none'`,
  `form-action 'none'` and `frame-src 'self'` keep fetch/XHR, form submission
  and external-frame traffic closed.
- Remember no longer saves the whole reply. One bounded model call extracts 1-5
  durable notes, and the pending-memory bar queues them for approval. Malformed
  output and timeouts are reported instead of showing an empty success.
- Assistant replies gain a speaker button with installed Windows voices and
  online natural Windows voices where offered, a speed control in Settings →
  Voice, and a Stop toggle. Speech stops when the chat changes or its message is
  removed.
- Replies saved with timing metadata show when they completed and how long they
  took - `26.7s`, `33m 42s` - persisted in SQLite. Replies written before this
  release keep their creation time and show no duration. Duration accumulates
  across Continue, and survives restart, branching and JSON export/import.
- Each provider has a brand-tinted mark wherever it appears: provider cards and
  the type select, the model picker, the composer chip, onboarding tiles, the
  sidebar status, the Models filter and the Voice transcription provider.
- Review fixes: atomic pending-note inserts, safe accent lookup, Markdown list
  markers, command-palette scrolling, cooldown colour, danger-control contrast,
  readable context counts, stacked project columns on narrow panes, project
  expansion after load, real artifact language labels, and truthful key and
  preview copy.

## Verification

- `npx tsc --noEmit`, `npm test` (591 tests), `npm run build`,
  `fallow dead-code`, `cargo fmt --check`,
  `cargo clippy --all-targets -- -D warnings`, `cargo test` (455 tests).
- OCR timed out; the review gate ran locally with AgentRouter GPT-5.6 Sol and
  then CodeRabbit, and the valid findings were fixed.

## Not in this release

- No bundled neural TTS model. Read aloud uses the Windows speech engine and the
  online natural voices Windows exposes.
- Artifact previews may load HTTPS assets but cannot call `fetch`, XHR or
  WebSockets, and WebRTC is not isolated.
- Remember uses the active chat's provider and model; there is no separate
  extraction-model setting.
