# Release v0.8.6 - Skill self-test line endings

Status: release candidate on 2026-11-02. Follows v0.8.5. No migration.

## What changes

- `tests/run.sh` and the skill CLIs are forced to LF via `.gitattributes`
  and normalized in the working tree.
- The installed `resources/skills` copy no longer contains CRLF in shell
  scripts, so `skills_doctor` does not fail with
  `/opt/skills/.../tests/run.sh: 2: set: Illegal option -` before running.
- Deck Builder, DOCX Writer, Sheet Builder and PDF Workbench self-tests can run
  from the packaged app.

## Verification

- Rebuilt and reinstalled 0.8.5, opened Settings > Skills, ran Deck Builder
  self-test and captured the CRLF failure.
- Normalized scripts + `.gitattributes`, then all four golden suites pass in
  `myagent-sandbox` with `--network none`.
- `npx tsc --noEmit`, `npm test`, `npm run build`, fmt, clippy, Rust tests.
