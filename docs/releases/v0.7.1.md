# Release v0.7.1 - DeepSeek V4 thinking controls

Status: shipped with v0.7.1 on 2026-10-29. Follows v0.7.0. No migration.

0.7.1 fixes DeepSeek V4: the thinking-level selector was disabled, the request
body never carried DeepSeek's thinking controls, and earlier assistant reasoning
was not replayed when tools were on.

## What changes

### Thinking levels

- `deepseek-flash`, `deepseek-v4-flash` and `deepseek-v4-pro` now show
  `No reasoning`, `Low`, `High` and `Max` in the reasoning-effort selector.
- `deepseek-chat` keeps no selector because it is the non-thinking legacy model.
- `deepseek-reasoner` stays readable as a retired thinking model, but the
  current DeepSeek V4 models are the supported path.

### Request shape

- Non-thinking turns send `thinking: { "type": "disabled" }`.
- Thinking turns send `thinking: { "type": "enabled" }` plus
  `reasoning_effort` set to `low`, `high` or `max`.
- The legacy `minimal`, `medium` and `xhigh` values are normalized to DeepSeek's
  supported levels (`low`, `high` and `high`).
- `No reasoning` is no longer dropped before the request is built.

### Current models and context

- The empty-catalogue fallback now seeds `deepseek-flash`,
  `deepseek-v4-flash` and `deepseek-v4-pro`.
- Those models use a 1M context fallback and report reasoning plus vision.
- Legacy `deepseek-chat` and `deepseek-reasoner` rows stay readable.

### Reasoning replay

- When tools are enabled, every earlier assistant turn now carries its
  `reasoning_content`, including turns that made no tool call. DeepSeek requires
  this passback and returns a 400 without it.
- The replay is limited to DeepSeek model IDs, so other providers do not receive
  an extra field.

## Tests

- Catalog tests cover DeepSeek V4 levels, the legacy chat model, the 1M context,
  and the explicit model-catalogue fallback.
- Rust tests cover the `thinking` toggle, effort normalization, current seeds
  and cross-turn `reasoning_content` replay.
- `npx tsc --noEmit`, `npm test -- --run`, `npm run build`,
  `cargo fmt --check`, `cargo clippy -D warnings` and `cargo test`.
