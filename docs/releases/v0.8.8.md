# Release v0.8.8 - Designed decks, visible output, PDF text fixes

Status: release candidate on 2026-11-02. Follows v0.8.7. No migration.

## What changes

- Deck Builder 2.0: seven themes, eleven layouts (`title`, `section`,
  `agenda`, `bullets`, `cards`, `stats`, `table`, `chart`, `image`, `quote`,
  `closing`), gradient backgrounds, accent orbs and chips, stat cards, card
  grids, styled tables, themed charts, aspect-preserving image crops, page
  numbers and speaker notes.
- `deckb render` writes `outputs/renders/slide-*.png`. `describe_image` now
  accepts `path=`, so the agent can look at rendered slides, PDF pages and
  extracted figures through the vision fallback model before delivering.
- `save_artifact` rejects PDF, Office, image and archive types. A model can no
  longer base64 a generated `.pptx` into an artifact card, which caused a
  duplicate output card and a slow round trip.
- `pdfwb replace --find TEXT --with TEXT` covers an exact string on a page and
  redraws the replacement, for simple fixes such as a matric number or date.
- `pdfwb` documents how to decompose a PDF and rebuild a similar document from
  its rendered look and extracted figures.
- Rendered previews under `outputs/renders` are excluded from user-facing
  outputs.

## Verification

- Deck spec rendered in the sandbox; cover, stats, cards, chart, table and
  section slides inspected visually.
- `pdfwb replace` tested on a generated PDF and verified with `text`.
- `deckb` suite now covers `cards`, `charts`, `render` and the new deck format.
- Frontend: tsc, Vitest, production build.
- Rust: fmt, clippy, cargo test.
