# Release v0.4.0 — sandbox + machine judgment + voice

Agent gets hands (sandbox), judgment (decision models), ears (voice),
and stamina (research lookups, subagents). Follows v0.3.0 exit.
Needs J12b MCP + J8 audit shipped (sandbox execs log via audit).

## R1. Research lookups (5–30min, websearch + fetch)
- Long job, not long prompt: query → planned searches (D15) → fetch
  loop (D14) → synthesized memo stored as chat result + artifact.
- Progress via todo list + streaming deltas; cancel anytime; cheap
  model for search passes, main model synthesizes (J5-style routing).
- Permissions: host-allow once per job or per-host Ask (D14 rules kept).
- Done: 30-min job returns memo, cancellable, no prompt storms.

## D18. Subagents
- Per `features.md:362`: delegate subtasks to agents with own context.
  Revisit gate met (D1-D17 solid). Child = task + capped excerpts;
  parent gets summary as tool output.
- Child inherits project scope; user-facing approvals surface once.
- Done: isolated subtask, one audit row per user-facing decision.

## S1. Sandbox (opt-in, foolproof) — plan: `docs/plan/v0.4.0-sandbox.md` (rev 2)
- Runtime: Docker Desktop (WSL2 backend) only. WSL2-direct dropped
  (one shared VM, net-off is VM-wide, `\\wsl$` widens the surface).
  Missing Docker = refuse to enable; never host-exec as "sandbox".
- No internet (`--network none`), one bind = the project dir with
  `.git`/`.vscode`/`.husky`/`.github` and agent-config files overlaid
  read-only; no home, vault, DB or Docker socket; digest-pinned image;
  `--rm` + `docker kill`; off by default.
- One runtime: a pinned Debian slim base pulled on Enable (the one
  consented network moment), then one local derived image built from a
  checklist plus an Advanced package box. No distro picker, no bundled tar.
- Tools: one container tool `sandbox_run`; read/glob/grep/write/edit/delete
  stay on the host behind a path jail (D8-D10). In sandbox mode
  `run_powershell` (D7) is inspection only (time, disk, biggest files);
  anything that creates, updates, deletes or runs project code goes to the
  sandbox. M1 pre-screens as UX, never as the boundary.
- Per exec: git checkpoint (`refs/myagent/pre-exec/<id>`) plus a
  sensitive-change receipt; undo UI stays in v2. Every exec audited (J8).
- Done: code runs, files change, nothing escapes, no net, all logged. The
  container tests are `#[ignore]`d behind `MYAGENT_SANDBOX_IT=1` because CI
  has no Docker; they run on the target machine before merge.

## M1. Decision models (local only, no Jev)
- Jev excluded: API-only, closed weights, BYOK-hostile (scout verified).
- Screen: `deberta-v3-base-prompt-injection-v2` (0.2B, Apache-2.0,
  ~138ms/inference measured, ONNX QUInt8, 244 MB) at the tool-boundary Ask
  branch → card warning, never silent Allow, escalate-only. Toxicity
  **deferred to V1** (HAP-125M warn-not-block on voice finals).
- Roles: (1) injection-screen at tool boundary; (2) cheap-router stays
  LLM (J5) — decision model is not the router; (3) agent-assist:
  score + reason + suggest-deny on ApprovalCard, human decides,
  assists never auto-allow.
- Defaults: warn-not-block; block only after calibration + opt-in.
- Done: injected prompt escalated, card shows machine judgment,
  audit row per flag.

## V1. Voice transcribe (hybrid, Rust-native)
- OpenWebUI/LobeHub pattern, adapted: webview mic (MediaRecorder
  16kHz) → frames to Rust → default local Moonshine sidecar
  (offline/private/free) + optional BYOK `/audio/transcriptions`
  (gpt-4o-transcribe etc via vault key) for quality.
- PTT first (button = turn boundary, skip VAD/SmartTurn); hands-free
  voice mode later with own short-answer system prompt. HAP
  warn-not-block on finals (guide §10). Accent set + WER test first.
- Done: PTT → text in composer; degraded accents surface notice.
