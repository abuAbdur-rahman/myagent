# Release v0.12.0 - message versions, queued turns, trusted context and inline visuals

Status: release candidate on 2026-11-10. Follows v0.11.0. Migrations 35, 36
and 37 add the message tree, temporary-chat marker and durable-memory trust.

## What changes

- Editing or regenerating a reply now creates a sibling version instead of
  replacing history. Version arrows switch the active thread, and artifacts
  follow the same regeneration history with a chronological selector and a
  safe Download all versions ZIP export.
- Sending while a reply is streaming queues the next turn. Queued messages are
  scoped to their chat and can be expanded, reordered, edited, sent next or
  removed before they drain one at a time.
- `/visualize` and `viz` fences add inline interactive visuals in the existing
  artifact sandbox. Mermaid diagrams and KaTeX math render in chat, and code
  stays plain while streaming before highlighting once the reply settles.
- Ctrl+K searches message text as well as chats. Temporary chats stay out of
  search and the sidebar, are visibly badged, and are discarded when left or
  swept at the next launch.
- Durable global and project memories are ranked against each user turn under
  one 2,500-character cap. Project chats propose shared-memory roll-ups on an
  explicit request, every tenth user turn and thread exit; private, secret,
  duplicate and tool-derived content remains filtered or untrusted.
- The context inspector assembles the next provider request through the real
  request path, redacts credential-shaped keys and strings, masks inline
  images, keeps oversized output valid JSON, and estimates request, message and
  per-tool tokens before redaction.
- Sandbox writes capture a checkpoint. A Changes view shows the patch and a
  confirmed undo restores tracked paths. PowerShell and its approval card start
  in the configured project folder.
- Global shortcuts cover stop, search, new chat, settings, sidebar and panel.
  Completion notifications appear only while the app is unfocused, and About
  can copy rotating, redacted diagnostics without prompts or API keys.
- The `/skill` picker searches enabled skills. Tool activity folds adjacent
  calls with the same display category while preserving chronology.
- The test gate now runs Vitest, TypeScript and Rust together. Recorded SSE
  fixtures cover normal, reasoning, tool, usage, length, multiline, multibyte
  and mid-stream failure paths, and Delete everything is proven across every
  database and app-file store.
- Security and reliability hardening closes MCP alias and envelope ambiguity,
  bounds skill and archive input, denies screen capture in artifact frames,
  preserves memory trust through approval and undo, and broadens credential
  redaction in inspection and diagnostics.

## Verification

- `npm test`, `npm run build`, `npx tsc --noEmit`, `fallow dead-code`,
  `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and
  `cargo test` pass locally.
- A read-only final review used the general agent with OCR explicitly disabled;
  confirmed findings were fixed before the release PR. The PR review gate is
  CodeRabbit only.

## Not in this release

- Provider capability metadata is not fetched for request-inspector effort
  clamping; displayed request size remains an estimate.
- Folders, permission modes, on-demand tool definitions, code mode, project
  instruction files, cost caps, model compare, cheap-model routing, quick ask,
  branch-tree navigation, scheduled runs and the local navigator remain
  unshipped.
