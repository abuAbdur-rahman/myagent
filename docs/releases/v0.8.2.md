# Release v0.8.2 - Host shell reads and clearer skills

Status: release candidate on 2026-11-01. Follows v0.8.1. No migration.

0.8.2 fixes the two dead ends seen in 0.8.1: a sandbox-mode host shell that
could not read anything outside the project, and a skills page that implied
built-in skills were installed.

## What changes

- With the sandbox on, `run_powershell` allows read-only inspection:
  `ls`, `cat`, `head`, `tail`, `wc`, `rg`, `grep`, `sort`, `uniq`, `df`, `du`,
  `file`, `stat`, `pwd`, `whoami`, `date`, plus `Get-ChildItem`, `Get-Content`,
  `Get-Item`, `Get-Process`, `Get-Service`, `Select-String`, `Join-Path`,
  `Test-Path` and similar.
- Quoted paths, `$HOME`, `$env:USERPROFILE`, pipelines and simple variable
  assignments are accepted, so `Get-ChildItem -LiteralPath "$HOME\Downloads"`
  and `rg "foo|bar" C:\Users\me\Downloads` work.
- Writes, deletes, installs and process launches stay blocked: `mkdir`,
  `touch`, `rm`, `del`, `Set-Content`, `New-Item`, `Out-File`, `Start-Process`,
  `python`, `npm`, `git`, `sed`, `awk`, `find`, redirection, subexpressions,
  backticks and script blocks.
- `rg --pre`, `rg --hostname-bin` and `sort -o` are blocked because they can run
  or write.
- Credential and secret paths are denied by name: `.ssh`, `.aws`, `.gnupg`,
  `.kube`, `id_rsa`, `id_ed25519`, browser login stores and `.env`.
- A refusal now says it is final and lists the read-only commands, instead of
  inviting another attempt.
- The skill tool returns `unknown skill: <id>; no skills are installed` or the
  list of available ids.
- The Skills empty state says the PDF and deck skills arrive in 0.9.0.

## Limits

- This is command-string filtering, not an OS boundary. It lowers the chance of
  a write or an execution but cannot prove one is impossible; the sandbox stays
  the boundary for project work.
- Reading any non-secret host file is now possible while the sandbox is on, by
  design. Turn the sandbox off if host reads should not be available.

## Verification

- Unit tests cover allowed read-only commands with quotes, variables,
  pipelines and assignments, and refuse mkdir, touch, redirection, `Out-File`,
  `sort -o`, `rg --pre`, subexpressions and credential paths.
- `npx tsc --noEmit`, `npm test`, `npm run build`.
- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`,
  `cargo test --lib`.
