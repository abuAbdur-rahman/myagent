# Release v0.8.4 - Fewer prompts, context inspector, background builds

Status: release candidate on 2026-11-01. Follows v0.8.3. No migration.

## What changes

### Approvals

- Default allow for read-only work: `sandbox_read`, `sandbox_glob`,
  `sandbox_grep`, `sandbox_run`, `web_search`, `web_fetch`, `skill`,
  `read_document`, `describe_image`, `todo_write`, `todo_set`, `get_time` and
  `recall_memory`.
- Writes, deletes, installs and `run_powershell` still ask.
- A credential path (`.env`, `.ssh`, `.aws`, `.gnupg`, `.kube`, keys, browser
  login stores) forces a review even for a read-only tool.
- For each remaining ask, a small decision model returns ALLOW, ASK or DENY in
  under three seconds. Timeout, error or an unclear answer keeps the approval
  card. A DENY is reported as denied.

### Context inspector

- New Gauge button in the chat header.
- Shows token usage and last-turn input/output, the current checklist, important
  context (project, instructions, memory), the assembled system prompt, message
  count, document attachments and indexed skills.
- Copy the system prompt from the panel.

### Background sandbox build

- `sandbox_enable` and `sandbox_rebuild` return immediately and build in the
  background.
- A floating status card follows the build across the app: preparing, pulling
  and building, ready, or failed with the error.
- Settings shows the current build stage and polls until the image is ready.

### Skills

- `skill` resolves aliases from the skill id, title or triggers; `pdf` loads
  `pdf-workbench`, `pptx` loads `deck-builder`, and unknown names still list the
  available ids.

## Limits

- The decision model uses the active model connection, so it costs a small
  request per unresolved approval.
- The aliases only resolve when exactly one skill matches.
- Background builds are not resumed after an app restart; a running Docker build
  is left to Docker.

## Verification

- `npx tsc --noEmit`, `npm test`, `npm run build`
- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`,
  `cargo test --lib`
- Docker checked locally (29.9.1) with the existing sandbox images.
