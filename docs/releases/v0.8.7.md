# Release v0.8.7 - Output cards, live checklist, named activity

Status: release candidate on 2026-11-02. Follows v0.8.6. No migration.

## What changes

- Files written by tools surface as output cards in the reply and in the Outputs
  panel. PDF, DOCX, PPTX and XLSX cards open an inline preview and expose a
  Download button that saves the file anywhere on the PC (`artifact_export`).
- The checklist refreshes when `todo_write` and `todo_set` finish, and
  `todo_finish` closes it when the run ends: normal runs complete the remaining
  items, stopped or truncated runs cancel them.
- The activity pill keeps its distance from the composer and names the running
  tool (`Searching the web`, `Working in PowerShell`, `Working in the sandbox`,
  `Updating the checklist`, and so on) instead of always saying Thinking.
- Interim narration from between tool calls gets a block separator, so it no
  longer runs into the final answer.
- A run that exhausts its tool-step budget emits `finish_reason = step_limit`
  and shows a Paused card with a Continue button that resumes the task.
- The context meter always shows a percentage. When a model reports no context
  window, it uses the default window and labels the value as assumed, so
  auto-compact is not blind.
- The skill index in the system prompt lists exact IDs in backticks, and the
  unknown-skill error lists the valid IDs.
- Outputs shows deliverables only. When a document or media file is produced,
  helper scripts, HTML and JSON from the same run are hidden.
- The reasoning selector is wide enough for "No reasoning", and "Used in this
  session" no longer shows a bare, unexplained count.
