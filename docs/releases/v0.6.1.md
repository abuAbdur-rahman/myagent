# Release v0.6.1 — MCP SSE and provider rotation fixes (patch)

Status: shipped with v0.6.1 on 2026-10-28. Follows v0.6.0. No migration.

0.6.1 is the review-fix patch for 0.6.0. It closes the legacy SSE session,
provider-key rotation and model-cache findings, fixes Windows stdio server
launches and makes raw clipboard images paste into the composer. No new provider
or MCP surface is added.

## What changes

- **Legacy SSE sessions.** A closed SSE stream is detected and evicted, so the
  next tool call reconnects instead of reusing a dead reader. Each request gets
  a unique JSON-RPC id, server-initiated requests are ignored, and the endpoint
  parser bounds unterminated lines and accumulated event data. A bearer token is
  only sent to an endpoint on the same origin as the SSE URL.
- **Windows stdio MCP launch.** `npx`/`npm`/`pnpm`/`yarn`/`uvx` shims resolve
  to their `.cmd` files and Rust's standard library handles batch escaping.
  PATH is built from the current environment, the registry and known tool
  directories; children run without a console window; and a cold install gets
  60 seconds instead of 20.
- **Provider key rotation.** Every request starts with the first key that is not
  cooling down. A quota-flavoured 429 or a payment-required response marks the
  active key exhausted; the request moves to another key when one is available,
  otherwise the error reports the cooldown. A plain 429 keeps the normal
  rate-limit backoff.
- **Model list refresh.** Refresh on Models bypasses the backend ten-hour cache
  as well as the picker cache. Empty lists are not cached, and a request that
  finishes after an invalidation cannot repopulate the cache. Stored cache
  entries are validated with Zod.
- **Provider dialog.** Retrying a draft provider replaces its draft key instead
  of appending another key.
- **Clipboard images.** Pasting a screenshot now works when the clipboard exposes
  the image as a clipboard item rather than a file. Unnamed pasted images get a
  generated name.

## What does not change

- MCP transports, OAuth, bearer storage, approvals, deny rules and tool
  namespacing from 0.6.0.
- The 0.5.1 Responses fallback and the 0.6.0 provider recovery, Ollama Cloud,
  AgentRouter retry and onboarding work.
- No migration; the database schema stays at 30.

## Roadmap added with this release

The MCP setup UX and Windows computer-use research is scheduled across
0.7.0–1.0.0 in `docs/plan/v0.7.0-to-v1.0.0-mcp-computer-use.md`. 0.7.0 covers the
Rust-owned MCP state machine, standard `mcpServers` import/export, Job Object
process lifetime, server logs, tool-hash re-approval and `server/discover`
fallback. 0.8.0–0.9.0 cover observe-only UIA and then semantic
actions with per-app tiers and safety controls. 1.0.0 integrates both.
