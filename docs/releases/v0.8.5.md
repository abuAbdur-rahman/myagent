# Release v0.8.5 - Clearer Sandbox page

Status: release candidate on 2026-11-01. Follows v0.8.4. No migration.

## What changes

- The Sandbox page is rebuilt around one status line: badge, Docker version,
  image size and Recheck. The three duplicated warnings are gone.
- Missing Docker, stopped Docker and a missing image each get one setup card and
  one primary action. Start Docker launches Docker Desktop; Recheck refreshes.
- The toolchain is three compact cards (Core / Office / Full) with their size.
- Packages, extra apt names, CPU and memory moved under Advanced.
- When ready, the page shows only the project folder, toolchain summary, Rebuild
  image and Allow installs.
- Background build status still appears in the floating card and as a single
  line on the page.

## Docker diagnostic

The reported `daemon.json is invalid ... signal: bus error` came with Docker's
backend stopped. `~/.docker/daemon.json` was valid JSON
(`builder.gc.defaultKeepStorage`, `experimental: false`). Restarting Docker
Desktop brought the engine back (29.9.1, existing sandbox images present), so no
configuration reset was needed. If it recurs, use Docker's **Reset
configuration**, not a full factory reset, then rebuild the sandbox image.
