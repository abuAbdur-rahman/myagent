# Release v0.7.0 - MCP setup UX and Windows computer use

Status: planned. Target: 0.7.0. Follows v0.6.1. Migration 31.

0.7.0 makes MCP servers easier to set up and safer to run, then adds a bundled
Windows computer-use server on top of the same MCP manager. It also fixes the
AgentRouter OpenAI Responses failure and restores visible reasoning where the
provider returns it.

## What changes

### AgentRouter OpenAI compatibility

- Responses requests stay stateless, and AgentRouter tool turns no longer replay
  `responses_items` from earlier requests. Those items carry Azure resource-bound
  ids and encrypted reasoning; a multi-node gateway can reject them with
  "The requested item was created under a different Azure OpenAI resource".
  Gateway turns are rebuilt from the chat-shaped history, keeping `call_id`
  pairing.
- A cross-resource, decryption or "items are not persisted" 400 retries once
  with an item-free body instead of aborting the turn.
- `reasoning.summary: "auto"` is requested with the effort, so AgentRouter GPT
  models show their thinking again. Encrypted reasoning is only requested for
  direct OpenAI replay.
- Regression tests cover the stateless request builder, gateway item stripping,
  cross-resource classification, reasoning-summary requests and the AgentRouter
  fallback path.

### MCP setup and safety

- **Structured config:** command, args, cwd, env, URL, headers and timeout.
  Existing `cmd`/`url` rows keep working through the same config path.
- **Portable import/export:** standard `mcpServers` JSON with `type`, `command`,
  `args`, `cwd`, `env`, `url`, `headers` and `timeout`. Import sanitizes names,
  dedupes, caps at 50 servers and 1 MB, and leaves imported servers disabled
  until you enable them. Export writes the current project or global scope.
- **Secrets stay in Windows Credential Manager:** env and header values can use
  `${secret:name}` references. The app owns
  `mcp:<server-id>:env|header:<key>` entries, blank values preserve stored
  secrets, and export blanks secret-like values and references. Custom header
  values are write-only in the settings panel; leave the field blank to keep
  the stored value. Cross-machine imports require re-entering secrets.
- **Windows process lifetime:** stdio children run in a Job Object with
  `KILL_ON_JOB_CLOSE`, so the child tree dies with the app. The existing `.cmd`
  shim resolution and `CREATE_NO_WINDOW` stay; no `cmd /c` string is built from
  config text.
- **Bounded logs:** each server keeps the last 200 stderr lines, capped at 2,000
  bytes per line. These are process output, not a redacted audit log.
- **Tool-definition approval:** the first successful probe stores a SHA-256 hash
  of the sorted tool names, descriptions and schemas. A later change marks the
  server `needs_review`, keeps its tools out of the catalog, and offers
  **Approve tools**.
- **Settings:** advanced command/args/cwd/env/header/timeout fields, per-tool
  ask/allow/block policy, import/export, logs, and the review action. Legacy
  `sse`, Streamable HTTP, stdio, bearer and OAuth servers keep working.

### Windows computer use

- Bundled `computer-use` stdio MCP server, seeded disabled in MCP settings and
  spawned by the MCP manager. It is never elevated and has no raw shell tool.
- **Observe:** `list_apps`, `list_windows`, `get_state` (compact UI Automation
  tree and optional PNG) and `screenshot`. UI Automation is the primary path;
  the screenshot is for canvas, Chromium and Electron surfaces.
- **Act:** `invoke`, `click`, `type_text`, `set_value`, `press_keys`, `scroll`,
  `drag`, `wait`, `focus_window`, `launch_app`, `read_clipboard` and
  `write_clipboard`.
- **Snapshots:** actions use snapshot-scoped runtime ids. Stale ids return
  `stale_snapshot`. The tree is capped at 1,200 nodes and depth 8, snapshots
  expire after 10 minutes, and coordinates are physical pixels with
  per-monitor DPI awareness v2.
- **Per-app allowlist:** executable path or process name, with `View`,
  `Interact` and `Full` tiers. Hard denies cover terminals, password managers,
  security tools, system processes, UAC/secure-desktop surfaces and password
  fields. User deny rules win over allow rules.
- **Kill switch and control:** a global hotkey (default `Ctrl+Alt+Shift+P`)
  toggles pause. Pause stops observation and actions. The settings page and an
  optional always-on-top overlay also pause and resume. Action budgets, dry-run,
  before/after audit thumbnails and confirmation for drag, clipboard write,
  `Alt+F4` and launch are enforced in the server.
- **Input guard:** keyboard and mouse input is sent only after the focused
  process or click point is confirmed to belong to the allowlisted app.
  Windows-key, `Alt+Tab`, `Alt+Esc`, `Ctrl+Alt+Del`, `Ctrl+Shift+Esc` and
  `Ctrl+Shift+Enter` sequences are denied. Snapshots re-find elements inside the
  captured window and reject an element that now belongs to another process.
- **Settings:** master toggle off by default, pause, dry-run, thumbnails,
  overlay, hotkey, action budget, allowlist editor, deny rules, hard-deny list,
  and an audit viewer with thumbnails and clear.

## What does not change

- Windows only. No macOS/Linux/mobile branches.
- No elevated agent, no secure-desktop input, no raw shell in the computer-use
  server, and no remote steering.
- No local screenshot/vision model; cloud vision only.
- Legacy `sse`, OAuth, bearer storage, tool namespacing and existing approvals
  keep working.
- The optional local navigator (`jevos-v5`) is not in 0.7.0.

## Deferred to 0.8.0

- Computer-use hardening and the scripted observe/action eval harness.
- Publisher-signature verification and yield-to-user pause detection.
- Protocol `server/discover` probing, `Mcp-Method` / `Mcp-Name` headers and
  `tools/list` `ttlMs` / `cacheScope` caching.
- A Rust-owned MCP state machine, Form/JSON tabs, a details page, a composer
  server chip, and error kinds with a next action.
- The optional local navigator experiment.

## Migration

Migration 31 adds `config_json` and `tool_hash`. Existing rows keep their name,
transport, auth, command/URL, policies and tokens. The old single `cmd` value is
read as the command; old URLs keep working. Secrets are not copied into SQLite.

## Tests and gate

- Unit: MCP config validation, secret references, portable import/export,
  tool-hash stability and changes, Job Object spawn, AgentRouter statelessness
  and reasoning summaries.
- Computer-use: hard denies, tier policy, key guards, snapshot caps, stale
  snapshots, dry-run, action budget and audit.
- `npx tsc --noEmit`, `npm test -- --run`, `npm run build`,
  `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test`,
  `fallow dead-code`, `git diff --check`.
- The scripted observe/action eval is a 0.8.0 gate; 0.7.0 ships the tools behind
  the allowlist, hard denies, pause, dry-run and audit.
