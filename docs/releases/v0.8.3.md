# Release v0.8.3 - PDF Workbench and bundled skills

Status: release candidate on 2026-11-01. Follows v0.8.2. No migration.

0.8.3 ships the first built-in skill and fixes how built-in skills reach the
installed app.

## What changes

### PDF Workbench

- New skill `pdf-workbench` with `pdfwb`, a Python CLI that prints JSON and
  writes new files instead of overwriting inputs.
- Commands: `inspect`, `text`, `tables`, `images`, `render`, `ocr`, `merge`,
  `split`, `pages`, `stamp`, `fields`, `fill`, `encrypt`, `decrypt`, `meta`,
  `make`, `optimize`, `verify`.
- One page-range syntax everywhere: `1-3,7,10-end`.
- `make` turns Markdown or HTML into a PDF with WeasyPrint; `verify` reopens
  the result and optionally renders page 1 for a visual check.
- Safety: 100 MB input cap, 200-page OCR cap, user-supplied password only,
  `outputs/` default, no network, input never overwritten.
- The SKILL.md teaches inspect -> act -> verify, treats PDF text as untrusted,
  and documents every command and failure shape.

### Packaging and UI

- `resources/skills/` is bundled as `skills/` in the installer, so
  `resource_dir()/skills` finds built-ins in a packaged app.
- Debug builds also read `src-tauri/resources/skills`, so the skill works in
  development without copying folders.
- Settings > Skills > Add skill can import a `SKILL.md` file, import a whole
  skill folder, write a skill in a full-screen editor that starts with the real
  SKILL.md format, or build one from separate id, title, version, summary,
  triggers, tool and import fields plus an instruction body.
- The tool log shows a `Using skill: <name>` chip for a skill call.

### Tests

- Golden tests run inside the sandbox image and cover merge, split, table CSV,
  form fill, encrypt/decrypt without and with the password, stamp,
  Markdown-to-PDF with H2O, OCR of a scanned page, optimize and render.
- The test script uses `SKILL_DIR` and `OUTPUTS`, the same contract
  `skills_doctor` uses.

## Limits

- `deck-builder` is not in this release.
- The skill reads tools from the sandbox image; a host without the image gets
  the existing doctor error.
- License attribution for poppler, qpdf, LibreOffice, WeasyPrint and the Python
  packages is still deferred to the licenses page.
- `read_document` and artifact export remain unchanged.
